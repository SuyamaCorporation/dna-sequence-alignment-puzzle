# DNA Sequence Alignment Puzzle

## 概要
2本のDNA配列を手動でアラインメントしてスコア最大化を狙うパズルゲーム。Needleman-WunschとSmith-Watermanアルゴリズムの最適解と比較できる。

## 機能
- 10問の内蔵パズル（10〜14塩基、難易度順）
- 配列間に「+」ボタンでギャップ（−）を挿入、ギャップクリックで削除
- リアルタイムスコア表示（マッチ+2、ミスマッチ−1、ギャップ−2）
- 最適グローバルアラインメント表示（Needleman-Wunsch法）
- 最適ローカルアラインメント表示（Smith-Waterman法）
- 動的計画法（DP）テーブルの表示・最適経路ハイライト
- ヒント機能（最適スコアとギャップ数のヒント）
- ストリーク・解決数をlocalStorageで保持

## 使い方
1. 「←/→」で問題を切り替え
2. Seq1・Seq2の「+」ボタンをクリックしてギャップを挿入
3. スコアを最適値に近づける
4. 「Solve (NW Global)」で正解を表示
5. 「DP Table」で動的計画法テーブルを確認

## スコアリング
- 一致（Match）: +2
- 不一致（Mismatch）: −1
- ギャップ（Gap）: −2
